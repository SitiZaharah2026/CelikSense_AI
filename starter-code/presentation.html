Agent Spotlight — ADHD

ADHD Adaptive Agent

Students with ADHD are fully capable learners — they just need a different environment. This agent designs reading sessions around their focus needs, not against them.

10-Minute Micro-Sessions
Long texts are split into short segments with planned breaks so students stay engaged without cognitive overload.
Reading Window
Highlights one line of text at a time, hiding surrounding content to eliminate visual distraction.
Focus Timer + Break Reminders
Adapted Pomodoro technique — work 10–15 min, rest 3 min, with gentle on-screen reminders.
Quick Note Builder
Capture key ideas with one click while reading — automatically compiled into a summary at the end.
AI Support

Gemini Pro generates session suggestions, interest-based topics, and reflection questions based on the student's text — all dynamically adapted to their current focus level.

Agent Spotlight — Dyslexia

Dyslexia Adaptive Agent

Dyslexia is not an intelligence problem — it is a visual text processing challenge. This agent transforms how text is presented so the student's brain can process it with far less effort.

OpenDyslexic Font
A specialised font with heavier bottoms on each letter, significantly reducing the letter-reversal rate common in dyslexic readers.
Skim Guide
AI highlights the key phrase in each paragraph so students can grasp the meaning without reading line by line.
Auto Mind Map
Any text is converted into a visual mind map by Gemini — relationships between ideas shown as a graphic, not a wall of words.
Text Simplification
Complex text is rewritten into short sentences, simple vocabulary, and bullet points using AI — on demand.
User Controls
Font size adjustable
Line spacing adjustable
Background colour changeable
Audio reading available
Powered by AI

Gemini Pro + Groq Llama handle simplification, mind maps, and reading suggestions — with full bilingual BM/EN support.

AI Architecture

ReAct Workflow — Think. Act. Observe.

Unlike simple chatbots that only answer questions, every CelikSense agent uses the ReAct reasoning loop — thinking before acting, and verifying after acting.

Input
Student submits text or command
→
Think
Agent analyses context & selects tool
→
Act
Calls tool (AI / OCR / TTS)
→
Observe
Evaluates output, retries if needed
→
Output
Delivers response to student
